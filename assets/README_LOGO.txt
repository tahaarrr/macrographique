Ce dossier n'est plus utilisé pour le logo.

Depuis la mise à jour "paramètres dynamiques", le logo de l'entreprise
(et toute l'identité de l'en-tête : nom société, adresse laboratoire,
référence document, mentions de bas de page) se configure directement
DANS L'APPLICATION, via l'écran "Paramètres" (icône ⚙️ en haut à droite
de l'écran d'accueil "Macrographique").

Le logo est importé depuis l'appareil (caméra ou galerie), stocké dans
le dossier privé de l'application, et automatiquement réutilisé dans
tous les PDF générés — sans avoir besoin de recompiler l'application.
